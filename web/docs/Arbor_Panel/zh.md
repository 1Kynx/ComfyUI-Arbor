# 面板

查看任何数据，或直接输入数据。接入时：显示输入并原样传出。未接入时：每行是一项，空一行开始新分支。（对应 Grasshopper 的 Panel）

## 输入

- **数据** `data` · *任意，可选*  
  任何数据——数据树、原生列表、图片、数字…… 不接则改为手动输入。
- **文本** `text` · *STRING*  
  手动输入的数据（未接入输入时使用），直接在面板里编辑。
- **识别数值** `parse_numbers` · *BOOLEAN*  
  像 7 / 3.5 / true 这样的行变成 INT / FLOAT / BOOLEAN，对应面板里的 123 / abc 按钮。
- **整段文本** `multiline` · *BOOLEAN*  
  整段文字作为一项，对应面板里的「逐行 / 整段」开关。

## 输出

- **数据** `data` · *任意 ×N*  
  原生列表：下游节点会对每一项各运行一次（只有一项时运行一次）。
- **数据树** `tree` · *数据树*  
  数据树形式——给 Arbor 节点用，保留分支结构。

## 查看（接入输入时）
- 数据树显示为可折叠的分支，带路径和数量（`{0;1} N=3`）；图片显示缩略图。
- 长文本默认折叠成四行，点「展开」查看全部。鼠标悬停某项可单独复制；工具栏按钮复制全部。
- **实时**：上游全是轻量数据节点（Arbor 的数据 / 数据树 / 列表节点、Primitive、字符串和数学节点）时，编辑就会实时刷新，无需运行（绿点）。上游有采样器、加载器等重节点时不会自动运行，显示上一次运行的结果。
- ⤢ 打开大窗口查看。

## 输入（未接入时）
- **逐行**：每行一项，空一行开始新分支。左侧标出每行的分支路径和序号，按类型着色（蓝色 = 数字，紫色 = 布尔值）。
- **整段**：整段文字作为一项——适合长提示词。
- **123 / abc**：识别数字和 true / false，或全部保留为文本。
- ⤢ 打开大编辑窗口。Ctrl+Enter 仍可运行工作流。

## 示例
```
3
5
7

a cat
a dog
```
→ 数据树 `{0}: [3, 5, 7]`，`{1}: ["a cat", "a dog"]`。
