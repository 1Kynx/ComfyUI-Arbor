# 列表 → 数据树

把原生列表收回成数据树。把当初送进「数据树 → 列表」的那棵树（或 XY 组合列表的形状）接到形状上，即可还原分支。

## 输入

- **列表** `list` · *任意*  
  原生列表，例如批量运行的逐项结果。
- **形状** `shape` · *任意，可选*  
  要复制其分支结构的数据树，项数必须与列表一致；不接则全部放进 {0}。
- **拆分批次** `split_batch` · *BOOLEAN*  
  重建前先把批次拆成单帧。

## 输出

- **数据树** `tree` · *数据树*  
  按形状排列好的值。

## 示例
形状 `{0}: a, b · {1}: c, d`，列表 `1, 2, 3, 4` → `{0}: 1, 2 · {1}: 3, 4`。

## 提示
- 数量不一致会报错，并给出两边的数量——通常是形状接错了树，和当初展开的那棵不是同一棵。
- 批次大小大于 1 时，每个结果都是一个批次；没关系，一个批次仍算一项。
