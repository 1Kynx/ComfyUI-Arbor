# 随机

带种子的打乱，或抽取若干项（可选允许重复）。种子相同，结果相同。

## 输入

- **数据** `tree` · *任意*  
  要打乱或从中抽取的项——普通数据或数据树（按分支处理）。
- **模式** `mode` · *COMBO (shuffle · pick · pick (repeats))*  
  shuffle 打乱：重新排序 · pick 抽取：抽 count 个不同的项 · pick (repeats)：抽 count 个，允许重复。
- **数量** `count` · *INT*  
  每个分支抽取的项数（打乱模式忽略）。
- **种子** `seed` · *INT*  
  随机种子——相同的种子总是得到相同的结果。
- **逐分支** `per_branch` · *BOOLEAN*  
  开启：每个分支分别处理。关闭：所有项当作一个列表。

## 输出

- **数据** `data` · *任意 ×N*  
  打乱 / 抽取后的项（普通数据）。
- **数据树** `tree` · *数据树*  
  打乱 / 抽取后的项，按分支排列。

## 提示
- 为批量出图随机挑选提示词或风格：面板（每行一个）→ **随机**（抽 4 个）→ XY 组合列表 / 数据树 → 列表。
- 把种子的「运行后操作」设为随机，每次运行都会重新抽取。
