# 交叉组合

按分支生成 A × B 的所有组合（对应 Grasshopper 的 Cross Reference）。开启分组时：行 = A，列 = B。

## 输入

- **A** · *任意*  
  第一组取值。
- **B** · *任意*  
  第二组取值。
- **分组** `group` · *BOOLEAN*  
  每个 A 项一个分支——结果可直接做网格（行 = A，列 = B）。

## 输出

- **A** · *数据树*  
  A 按 B 的个数重复。
- **B** · *数据树*  
  B 按 A 的个数循环。

## 示例
A `3, 5`，B `x, y, z`，开启分组：
- A → `{0;0}: 3, 3, 3 · {0;1}: 5, 5, 5`
- B → `{0;0}: x, y, z · {0;1}: x, y, z`

## 提示
- 做 XY 对比图时，**XY 组合列表** 一个节点就能完成组合和展开。
- 开启分组时，每个子分支以对应的 A 值命名（图片等非文字的值用序号），原来的分支成为父分支并保留名字：`Mira · lab coat`、`Arrival · 2`。**图像网格** 会用它标注行；B 可作为列标签。
