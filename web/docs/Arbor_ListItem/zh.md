# 列表取项

从每个分支取第 i 项（对应 Grasshopper 的 List Item）。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **序号** `index` · *INT*  
  项序号；负数从末尾数（−1 = 最后一项）。
- **循环** `wrap` · *BOOLEAN*  
  序号超出长度时循环。关闭时超出范围得到空值。

## 输出

- **数据树** `tree` · *数据树*  
  每个分支取出的一项。

## 示例
序号 1：`{0}: a, b, c · {1}: d, e` → `{0}: b · {1}: e`
