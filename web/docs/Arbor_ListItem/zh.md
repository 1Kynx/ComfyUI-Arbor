# 列表取项

按序号、列表、范围或切片从每个分支取项——一个节点包含 Grasshopper 的 List Item 和 Sub List。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **序号** `index` · *STRING / INT*  
  取哪些项：`0` · `-1`（最后一项）· `0, 2` · `1:4`（切片，不含结尾）· `2-5`（范围，含结尾）· `::2`（隔一个取一个）。也可以接入数字。
- **循环** `wrap` · *BOOLEAN*  
  序号超出分支长度时循环。关闭时得到空值，各分支仍保持对齐。

## 输出

- **数据树** `tree` · *数据树*  
  按分支取出的项。

## 示例
`{0}: a, b, c, d · {1}: e, f`：

| 序号 | 结果 |
|---|---|
| `1` | `{0}: b · {1}: f` |
| `-1` | `{0}: d · {1}: f` |
| `0, 2` | `{0}: a, c · {1}: e, e`（循环） |
| `1:` | `{0}: b, c, d · {1}: f` |
| `::2` | `{0}: a, c · {1}: e` |

`:-1` 和 `1:` 能把每一项和下一项配成对（a → b、b → c、c → d）：模板 *arbor_h3_continuous_shots* 就这样取首帧和尾帧。**批次挑选** 用的是同样的写法。
