# 重复

重复项：each 得到 aabbcc，whole 得到 abcabc。接上形状时，改为把每个分支拉长到对应分支的项数——即 Grasshopper 的 Longest List。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **次数** `count` · *INT*  
  重复的次数（接了形状时不起作用）。
- **模式** `mode` · *COMBO (each · whole)*  
  each：每项原地重复 · whole：整个列表重复。接形状时：each 均匀铺开（a a b b），whole 循环（a b a b）。
- **形状** `shape` · *任意，可选*  
  可选，要对齐的数据树。分支按顺序配对（不够时重复最后一个）；每个分支拉长到对应分支的项数并沿用它的路径，结果与形状逐项对齐。

## 输出

- **数据树** `tree` · *数据树*  
  处理后的数据树。

## 示例
次数 2：`a, b` → each `a, a, b, b` · whole `a, b, a, b`

## 对齐形状
每个场景一个地点、两个镜头：
```
数据 = {0}: 茶室 · {1}: 竹林 · {2}: 天台
形状 = {0}: 镜头1, 镜头2 · {1}: 镜头1, 镜头2 · {2}: 镜头1, 镜头2
→ {0}: 茶室, 茶室 · {1}: 竹林, 竹林 · {2}: 天台, 天台
```
两边再各接 **数据树转数据**，就得到两个逐项对齐的六项列表——每个镜头都拿到自己场景的地点作参考图。模板：*arbor_h3_two_characters*。
