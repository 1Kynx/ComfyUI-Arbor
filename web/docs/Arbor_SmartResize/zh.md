# 智能缩放

按长边 / 短边 / 百万像素 / 框内适配 / 填满裁切 / 倍数缩放，并把两边对齐到 8、16、64 的倍数。

## 输入

- **图像** `image` · *IMAGE*  
  要缩放的图像或批次。
- **模式** `mode` · *COMBO*  
  目标尺寸的计算方式，只显示所选模式需要的参数。
  - **尺寸** `size` · *INT*  
    长边 / 短边的目标像素。
  - **百万像素** `megapixels` · *FLOAT*  
    目标面积（1.0 ≈ 1024 × 1024），保持宽高比。
  - **宽度** `width` · *INT*  
    目标框宽度。
  - **高度** `height` · *INT*  
    目标框高度。
  - **倍数** `factor` · *FLOAT*  
    缩放倍数（2.0 = 放大一倍）。
- **对齐倍数** `multiple_of` · *COMBO (1 · 8 · 16 · 32 · 64)*  
  两边都取整到这个数的倍数——扩散模型建议 8 / 16 / 64。
- **缩放算法** `method` · *COMBO (lanczos · bicubic · bilinear · area · nearest-exact)*  
  lanczos 最锐利；大幅缩小时 area 效果最好。
- **允许放大** `allow_upscale` · *BOOLEAN*  
  关闭后永远不会把图片放大。
- **遮罩** `mask` · *MASK，可选*  
  可选遮罩，按与图像完全相同的方式缩放（和裁切）。

## 输出

- **图像** `image` · *IMAGE*  
  缩放后的图像。
- **遮罩** `mask` · *MASK*  
  缩放后的遮罩（未接遮罩时为全 1）。
- **宽度** `width` · *INT*  
  最终宽度。
- **高度** `height` · *INT*  
  最终高度。

## 模式
| 模式 | 结果 |
|---|---|
| longest side 长边 | 长边 = 尺寸，保持比例 |
| shortest side 短边 | 短边 = 尺寸，保持比例 |
| megapixels 百万像素 | 面积 ≈ 百万像素，保持比例 |
| fit inside 框内适配 | 能放进 宽 × 高 的最大尺寸（不裁切） |
| fill & crop 填满裁切 | 正好 宽 × 高，居中裁切 |
| scale 倍数 | 两边乘以倍数 |

## 示例
500 × 300 的图，*长边* = 1000，*对齐倍数* = 64 → **1024 × 576**。

## 提示
- 用宽度 / 高度输出驱动同尺寸的空 Latent。
