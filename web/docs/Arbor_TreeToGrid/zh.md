# 图像网格

把图像数据树排成 XY 对比图：每个分支一行，每项一列。

## 输入

- **图像** `images` · *任意*  
  图像数据树，每个分支一行。普通图像列表 = 一行；批次会增加列。
- **行标签** `row_labels` · *任意，可选*  
  每行一个标签：列表，或每行一个分支的数据树（XY 组合列表的 x 输入、交叉组合的 A 可直接接）。
- **列标签** `col_labels` · *任意，可选*  
  每列一个标签：列表，或每个分支存放列值的数据树（XY 组合列表的形状、交叉组合的 B 可直接接）。
- **适配** `fit` · *COMBO (fit · original · stretch)*  
  不同尺寸的图片如何填充格子：fit 缩放适配、original 原尺寸、stretch 拉伸。
- **格子尺寸** `cell_size` · *INT*  
  格子长边像素；0 = 最大图片的尺寸。
- **间距** `gap` · *INT*  
  格子之间以及四周的留白像素。
- **字号** `font_size` · *INT*  
  标签字号。系统装有中日韩字体时，中文标签会正常显示。
- **主题** `theme` · *COMBO (light · dark)*  
  浅色或深色背景。
- **路径作行标签** `path_labels` · *BOOLEAN*  
  没有接行标签时，用分支路径作为行标签。

## 输出

- **图像** `image` · *IMAGE*  
  合成后的对比图（一张）。

## 用法
1. 把图片整理成「每个分支一行」的数据树——例如用 **列表 → 数据树** 并接上 **XY 组合列表** 的形状。
2. x 的取值接 *行标签*，形状（或 y 的取值）接 *列标签*。
3. 想交换行列，在本节点前加 **翻转矩阵**。

## 提示
- 过长的标签最多折成三行，超出部分用「…」省略。
- 整张图用「保存图像」保存；想把每格单独存下来，用 **按路径保存图像**。
