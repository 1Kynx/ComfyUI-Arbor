# 批次挑选

按序号、闭区间或切片从图像批次中挑帧，保留顺序和重复。

## 输入

- **图像** `images` · *IMAGE*  
  要挑选的图像批次。
- **序号** `indices` · *STRING*  
  用逗号或空格分隔：0, 2, -1（倒数）, 3-5（闭区间）, 1:8:2 或 ::2（Python 切片）。

## 输出

- **图像** `images` · *IMAGE*  
  挑出的帧，合成一个批次。
- **数量** `count` · *INT*  
  挑出的帧数。

## 示例（6 帧的批次）
| 序号 | 结果 |
|---|---|
| `0, -1` | 第一帧和最后一帧 |
| `2-4` | 2, 3, 4 |
| `::2` | 0, 2, 4 |
| `1, 1, 1` | 第 1 帧重复三次 |

## 提示
- 序号超出批次范围会直接报错而不是跳过，避免输错了却没发现。
