# 移动路径

去掉路径层级：+1 去掉第一级，−1 去掉最后一级；落到同一路径的分支会合并（对应 Grasshopper 的 Shift Paths）。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **偏移** `offset` · *INT*  
  正数去掉开头的层级，负数去掉末尾的层级。

## 输出

- **数据树** `tree` · *数据树*  
  处理后的数据树。

## 示例
偏移 −1：`{0;0}: a · {0;1}: b · {1;0}: c` → `{0}: a, b · {1}: c`（撤销升树）。
