# 构建数据树

用普通数据构建数据树：所有项放在一个路径上，或——接入结构时——按另一棵树的分支把项收回去。

## 输入

- **数据** `data` · *任意*  
  任意值或普通数据（原生列表），例如批量运行的结果。
- **路径** `path` · *STRING*  
  未接结构时放置这些项的分支路径，例如 {0} 或 {0;2}。
- **结构** `shape` · *任意，可选*  
  要复制其分支结构的数据树——XY 组合列表的结构，或当初展开的那棵树。项数必须一致。
- **拆分批次** `split_batch` · *BOOLEAN*  
  先把 IMAGE / MASK / LATENT 批次拆成每帧一项。

## 输出

- **数据树** `tree` · *数据树*  
  构建好的数据树。

## 两种用法
| 接入 | 结果 |
|---|---|
| 只接数据 | 所有项放在 *路径* 上：`{0}: a, b, c` |
| 数据 + 结构 | 按结构的分支收回：结构 `{0}: ·, · · {1}: ·, ·` + `a b c d` → `{0}: a, b · {1}: c, d` |

## 往返
数据树 → **XY 组合列表**（只接 x）→ 普通节点逐项运行 → **构建数据树**（*结构* 接 XY 组合列表的结构）→ 结果回到原来的分支。

## 提示
- 数量不一致会报错，并给出两边的数量——通常是结构接错了树，和当初展开的那棵不是同一棵。
- Arbor 的每个数据树输入本来就接受普通数据（作为 `{0}`）；需要指定路径、按结构收回或拆分批次时才用本节点。
