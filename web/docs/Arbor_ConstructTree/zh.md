# 构建数据树

把任意值、原生列表或批次包装成数据树的一个分支。

## 输入

- **数据** `data` · *任意*  
  任意值或原生列表。
- **路径** `path` · *STRING*  
  放置这些项的分支路径，例如 {0} 或 {0;2}。
- **拆分批次** `split_batch` · *BOOLEAN*  
  把 IMAGE / MASK / LATENT 批次拆成每帧一项。

## 输出

- **数据树** `tree` · *数据树*  
  只有一个分支（位于该路径）的数据树。

## 提示
- Arbor 的每个数据树输入本来就接受普通值和列表（会变成 `{0}`）；需要指定路径或拆分批次时才用本节点。
- 多个结果用 **合并**（相同路径合并）或 **编织**（每个输入各成一个分支）组合起来。
