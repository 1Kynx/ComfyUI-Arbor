# 序号切换

按序号传出第 N 个输入（按已连接的输入计数，循环）。未选中的输入不会被计算。

## 输入

- **序号** `index` · *INT / BOOLEAN*  
  0 = 第一个已连接的输入；负数从末尾数；会循环。也可接 BOOLEAN：False = 0，True = 1。
- **输入** `inputs` · *任意 × N，连接后自动增加*  
  任意类型的候选输入，每连一个就多出一个输入口；只有被选中的才会计算。

## 输出

- **输出** `output` · *任意*  
  被选中的输入。
- **数量** `count` · *INT*  
  已连接的输入数量。

## 提示
- 在工作流的整条分支之间切换（模型、提示词、图片来源），其余分支完全不计算。
- 用 **数值滑块**（*整数* 输出）或布尔值驱动 *序号*，就是一个 if / else。
- ComfyUI 自带的 If/Else Switch 只能接两路；本节点最多 32 路。
