# 加载素材

从硬盘任意位置挑选图片、视频和音频，分组成带名字的分支——相当于把多个「加载图像」合成一个节点，带浏览窗口和缩略图。文件原地使用，不复制。

## 输入

- **文件夹** `folder` · *STRING*  
  基准文件夹：列表里的相对路径从这里读取，「浏览…」也从这里打开。绝对路径；output/… 表示 ComfyUI 的 output 文件夹；arbor:… 表示 Arbor 自带的示例素材；其它相对路径都在 input 文件夹里。
- **文件** `files` · *STRING*  
  文件列表（以文本保存）：「# 名字」开始一个有名字的分组，空一行开始新分组，其余每行一个文件——相对于文件夹，或绝对路径。可以在节点的「文本」视图里直接编辑，也可以用「浏览…」添加。

## 输出

- **文件** `files` · *数据树*  
  全部文件，每个分组一个分支，并以分组命名——可以接对比查看器、按路径保存或面板。
- **图片** `images` · *数据树*  
  只有图片（IMAGE），分组相同——接「数据树转数据」后给图片节点，或接图像网格。
- **视频** `videos` · *数据树*  
  只有视频（VIDEO），分组相同。
- **音频** `audio` · *数据树*  
  只有音频（AUDIO），分组相同。
- **文件名** `names` · *数据树*  
  不带扩展名的文件名，结构同「文件」——可作单元格说明，或给「按路径保存」命名。

## 用法
- **浏览…** 打开文件窗口：点击选择文件（双击直接添加一个），再点 **添加选中**；或点 **添加整个文件夹**——每个子文件夹成为一个以它命名的分组，和「加载文件夹」一样。
- 文件会加到最后点击的分组里；**+ 分组** 新建分组。在分组标题上改名，拖动缩略图调整顺序或移到别的分组，× 移除。
- **文本** 视图显示列表本身——可以粘贴路径、写「# 名字」、删除行。

```
# Arrival            →  文件 {0} Arrival：2 张图片
0 · Arrival/000.jpg
0 · Arrival/001.jpg

# Sound              →  文件 {1} Sound：1 段音频
C:/music/theme.wav
```

## 加载素材还是加载文件夹？
- **加载素材**：只读你挑选的文件，按你排的顺序，可以来自任何位置——列表随工作流保存。
- **加载文件夹**：读取文件夹里的全部文件，每次运行都重新读取——新增的文件会自动包含进来。

## 提示
- 在运行 ComfyUI 的这台电脑上可以浏览整个硬盘；从其它电脑访问时只能浏览 ComfyUI 的 input / output 文件夹（直接输入路径仍然可用）。
- 模板使用 `arbor:storyboard`，即 Arbor 自带的示例关键帧。
- 列表中的文件有改动时，节点会自动重新运行。
