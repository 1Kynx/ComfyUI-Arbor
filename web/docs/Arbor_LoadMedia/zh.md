# 加载素材

从硬盘任意位置挑选图片、视频和音频，分组成带名字的分支——相当于把多个「加载图像」合成一个节点，用系统自带的文件窗口选择，带缩略图。文件原地使用，不复制。

## 输入

- **文件** `files` · *STRING*  
  文件列表（以文本保存）：「# 名字」开始一个有名字的分组，空一行开始新分组，其余每行一个文件——绝对路径、output/…（ComfyUI 的 output 文件夹）、arbor:…（Arbor 自带的示例素材），或相对于 input 文件夹的路径。可以在节点的「文本」视图里直接编辑，也可以用「添加…」添加。

## 输出

- **文件** `files` · *数据树*  
  全部文件，每个分组一个分支，并以分组命名——这就是数据树：可以接交叉引用、取分支、对比查看器、按路径保存或面板。
- **文件名** `names` · *数据树*  
  不带扩展名的文件名，结构同「文件」——可作单元格说明，或给「按路径保存」命名。
- **图片** `images` · *IMAGE ×N*  
  全部图片（IMAGE），按列表顺序输出为普通数据——可直接接图片节点，每张图运行一次。
- **视频** `videos` · *VIDEO ×N*  
  全部视频（VIDEO），普通数据。
- **音频** `audio` · *AUDIO ×N*  
  全部音频（AUDIO），普通数据。

## 用法
- **添加…** 打开系统的文件窗口：选中一个或多个图片、视频、音频文件，点 **添加**——它们会放进选中的分组。
- 想添加**整个文件夹**：进入这个文件夹，不选任何文件直接点 **添加**（文件名框里是「（添加当前文件夹）」）——其中所有媒体文件都会加入，每个子文件夹成为一个以它命名的分组，和「加载文件夹」一样。
- 文件会加到最后点击的分组里；**+ 分组** 新建分组。在分组标题上改名，拖动缩略图调整顺序或移到别的分组，× 移除。
- **文本** 视图显示列表本身——可以粘贴路径、写「# 名字」、删除行。

```
# Arrival                              →  文件 {0} Arrival：2 张图片
output/shots/arrival_01.png
output/shots/arrival_02.png

# Sound                                →  文件 {1} Sound：1 段音频
C:/music/theme.wav
```

## 数据树还是数据？
- **文件** / **文件名** 保留分组：每个分组一个分支，并以分组命名。需要分组的地方用它们——**交叉引用** 把每个分组和别的数据配对，**取分支** 取出其中一组（*{0}* 或分组名）。
- **图片** / **视频** / **音频** 是普通数据：这一类的全部文件，按列表顺序，不带分组。可以直接接普通节点，每个文件运行一次。

## 加载素材还是加载文件夹？
- **加载素材**：只读你挑选的文件，按你排的顺序，可以来自任何位置——列表随工作流保存。
- **加载文件夹**：读取文件夹里的全部文件，每次运行都重新读取——新增的文件会自动包含进来。

## 提示
- 系统窗口在运行 ComfyUI 的电脑上打开，返回真实路径，所以不需要复制文件；会从上次选择的位置打开。macOS / Linux 上只能选文件——文件夹请在「文本」视图里输入。从其它电脑访问时，请在「文本」视图里直接输入路径。
- 位于 ComfyUI output 或 input 文件夹里的文件会写成短路径（`output/…`、相对路径），ComfyUI 换位置后工作流仍然可用。
- 模板使用 `arbor:storyboard/…`，即 Arbor 自带的示例关键帧。
- 列表中的文件有改动时，节点会自动重新运行。
