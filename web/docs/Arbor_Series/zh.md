# 等差数列

已弃用——请改用「数列」（模式 series）。等差数列：起始值、起始值 + 步长……共 count 个数。

## 输入

- **起始值** `start` · *FLOAT*  
  第一个数。
- **步长** `step` · *FLOAT*  
  相邻两数之差（负数为递减）。
- **数量** `count` · *INT*  
  数的个数。
- **输出整数** `as_int` · *BOOLEAN*  
  输出整数——用于种子、步数、尺寸。

## 输出

- **数据** `data` · *FLOAT / INT ×N*  
  这些数（普通数据）——可直接接 cfg、步数、种子等参数（每个数运行一次），也可接任何 Arbor 输入。

## 示例
| 起始值 | 步长 | 数量 | 结果 |
|---|---|---|---|
| 0 | 1 | 5 | 0, 1, 2, 3, 4 |
| 3 | 2 | 4 | 3, 5, 7, 9 |
| 1000 | 1 | 4（输出整数） | 四个连续的种子 |
