# 对比查看器

对比任意尺寸的图片、视频和音频：拖动滑条逐个切换，或用「对比」模式把 A 和 B 放在一起比较。视频和音频同步播放，切换时保持在同一时刻。

## 输入

- **输入** `images` · *IMAGE / VIDEO / AUDIO / 数据树 × N，可选，连接后自动增加*  
  要对比的内容——图片、视频或音频：单个、批次、列表或数据树都可以。每连一个就会多出一个输入口；图片批次每帧一页，音频批次每段一页（最多 64 页）。有名字的分支（加载的文件夹、分镜的场景）用名字标注。
- **标签** `labels` · *任意，可选*  
  可选，每一项的标签，按分支、逐项对应——一个列表可以用于所有分支。标签跟在分支名后面：Mei · Back、Kai · Close-up。

## 用法
- 接入一个或多个输入：图片、视频（例如「加载文件夹」类型选 *videos*、「创建视频」）或音频，可以混合。
- **切换**：一次显示一页，拖动画面下方的滑条或按 **← / →** 切换。
- **对比**：用工具栏里的胶囊选择 **A**，滑条选择 **B**。两个都是图片或视频时左右分屏，分割线跟随鼠标；只要有一个是音频就上下排列，A 在上，听到的是鼠标所在的那一半。
- 视频和音频共用一条 **播放 / 定位 / 循环** 控制条（空格键播放、暂停）。切换页面时保持当前时间——来回切换就能对比同一时刻的不同版本。较短的片段停在最后一帧。
- 音频显示波形，点击波形可以跳转。
- **原比例**：保持图片之间的相对大小（512 像素的图看起来是 1024 的一半）；**填充**：每张图都铺满画面。
- 双击画面（或点 ↗ 按钮）在新标签页打开当前文件。

## 标签
每页默认用所在分支的名字。接上 *标签* 可以给每一项命名：按人物分支的图片（`Mei`、`Kai`）配上标签 `original, 45°, 90° ……`，翻页时显示 *Mei · original*、*Mei · 45°* …… *Kai · 315°*。

## 一次看一个分支
内容来自多个有名字的分支时，工具栏会出现一个分支胶囊，可选择 *全部*、*Mei* 或 *Kai*（顶层分支；没有名字的数据树按输入区分）：滑条、对比模式和 A 菜单都只在这个分支里切换。选择会随工作流保存。模板：*arbor_qwen_camera_angles*。

## 提示
- 可以直接接原生列表（例如 XY 批量运行的逐项结果），节点会一次收下整个列表，而不是逐项运行。
- 已在 ComfyUI 的 output / input 文件夹里的视频直接播放原文件；其它视频先写到临时文件夹。
- 对比模式下一次只听一侧：左右分屏时听占画面更多的一侧，上下排列时听鼠标所在的那一半。喇叭按钮可以全部静音。
- 选择的模式、缩放方式和循环开关会随工作流保存。
