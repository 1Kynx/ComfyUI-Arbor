# 图像滑块对比

对比任意数量、任意尺寸的图片：拖动滑条逐张切换，或切到「对比」模式左右分屏比较。

## 输入

- **图像** `images` · *IMAGE / 数据树 × N，可选，连接后自动增加*  
  要对比的图片——单张、批次或图像数据树。每连一个就会多出一个输入口；批次会拆成每帧一页（最多 64 页）。有名字的分支（加载的文件夹、分镜的场景）用名字标注。

## 用法
- 接入一张或多张图片，一个批次会算作多页。
- **切换**：一次显示一张，拖动画面下方的滑条或按 **← / →** 切换。
- **对比**：用工具栏里的胶囊选择 **A**，滑条选择 **B**，分割线跟随鼠标移动。
- **原比例**：保持图片之间的相对大小（512 像素的图看起来是 1024 的一半）；**填充**：每张图都铺满画面。
- 双击画面（或点 ↗ 按钮）在新标签页打开原图。

## 提示
- 可以直接接原生列表（例如 XY 批量运行的逐项结果），节点会一次收下整个列表，而不是逐项运行。
- 选择的模式和缩放方式会随工作流保存。
