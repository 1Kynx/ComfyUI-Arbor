# 取分支

按路径（如 {0;1}）或分支名取出分支，多个用逗号分隔；路径留空时按序号取一个（对应 Grasshopper 的 Tree Branch）。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **路径** `path` · *STRING*  
  路径如 {0;1}，或分支名如 Mei，多个用逗号分隔（Mei, Kai）；留空则按序号取。
- **序号** `index` · *INT*  
  路径为空时使用的分支序号；会循环，−1 = 最后一个分支。

## 输出

- **数据树** `tree` · *数据树*  
  只含这些分支的数据树，路径和名字不变。
- **数据** `data` · *任意 ×N*  
  这些分支的各项，依次作为普通数据——可直接接逐项运行的节点。

## 示例
**加载素材** 里有分组 `# Mei`、`# Kai` 和 `# Places`：一个 **取分支** 填 *Mei, Kai*，另一个填 *Places*，就把人物和场景分开了，再用 **交叉引用** 让每个人物和每个场景配对——`{0} Mei` 和 `{1} Kai`，各三个场景。

## 提示
- 路径或分支名不存在时会报错，并列出实际存在的路径。
