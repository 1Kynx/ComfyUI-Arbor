# 取分支

按路径（如 {0;1}）取出一个分支；路径留空时按序号取（对应 Grasshopper 的 Tree Branch）。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **路径** `path` · *STRING*  
  完整路径，如 {0;1}；留空则按序号取。
- **序号** `index` · *INT*  
  路径为空时使用的分支序号；会循环，−1 = 最后一个分支。

## 输出

- **分支** `branch` · *数据树*  
  只含该分支的数据树。

## 提示
- 路径不存在时会报错，并列出实际存在的路径。
