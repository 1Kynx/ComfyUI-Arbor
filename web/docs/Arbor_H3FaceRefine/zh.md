# MiniMax H3 小脸修复

重画蒙版里的小脸。把每张脸裁出来，放大后低噪声重画，再羽化贴回。其余帧和像素保持不变。

## 输入

- **模型** `model` · *MODEL*  
  H3 模型，接在 LoRA 之后。请接在分块精修之前：裁切后的画面不需要分块。
- **VAE** `vae` · *VAE*  
  H3 视频 VAE。
- **CLIP** `clip` · *CLIP*  
  H3 文本编码器。
- **图像** `images` · *IMAGE*  
  成片的帧。
- **蒙版** `masks` · *MASK，可选*  
  要重画的脸，每帧一张蒙版，任何工具生成的都可以。用原生 SAM3 时，接 SAM3 Video Track，再接 SAM3 Track to Mask，在它的 `object_indices` 里写要修的对象。跟踪的提示词写 `face:16`：`:N` 是最多找几个，只写 `face` 只会找一个。主角可以留在这里，主角蒙版会把他们去掉。
- **主角蒙版** `lead_masks` · *MASK × N，可选，连接后自动增加*  
  每个主角一张蒙版。各自单独重画，并使用编号相同的参考图。不接参考图时按提示词单独重画，也可以用来分开连在一起的两张脸。
- **参考图** `references` · *IMAGE × N，可选，连接后自动增加*  
  主角的图片，对应编号相同的主角蒙版。
- **采样器** `sampler` · *SAMPLER*  
  接 KSamplerSelect，和自定义采样器一样。测试用的是 `lcm`。
- **Sigmas** `sigmas` · *SIGMAS*  
  重画强度，和自定义采样器一样。起点越低越保留原来的脸。测试用的是 Manual Sigmas `0.7, 0.494118, 0`。
- **提示词** `prompt` · *STRING*  
  所有被重画的脸共用的一句描述。
- **种子** `seed` · *INT*  
  噪声种子。每个裁切区域会加上自己的偏移。
- **精修尺寸** `refine_size` · *INT*  
  裁切区域重画前，短边放大到的像素数。768 就是 H3 原生 1344 × 768 的短边。
- **参考范围** `context` · *FLOAT*  
  裁切框是人脸的多少倍。调小后脸占满框、放大更多；调大后模型能看到更多周围的画面。不影响哪些脸共用一个框。
- **最大人脸** `max_face` · *INT*  
  始终大于这个像素数的脸保持不变。有过小于它的时候（比如推镜），整段都重画。
- **合并尺寸** `group_size` · *INT*  
  0 = 每张脸单独一个框，画得最好。大于 0 时，相邻的脸共用一个框，框的短边不超过这个像素数，人多时更快。可以用 288。
- **贴回方式** `paste` · *COMBO (mask · bbox)*  
  贴回的范围：`mask` 沿蒙版的人脸轮廓，`bbox` 用人脸外的稳定方框。
- **外扩** `grow` · *FLOAT*  
  贴回范围超出人脸多少，按人脸尺寸的比例计算。需要盖住头发。
- **羽化** `feather` · *FLOAT*  
  贴回边缘的柔和程度，按人脸尺寸的比例计算。

## 输出

- **图像** `images` · *IMAGE*  
  小脸重画后的视频。
- **小脸片段** `face_clips` · *IMAGE*  
  每个裁切区域重画后、缩回之前的画面，首尾相接。形状不同的片段居中放在黑底上。接到视频节点可以看模型实际画了什么，哪段属于哪个裁切框见报告。
- **报告** `report` · *STRING*  
  每张脸一行：编号、帧范围、位置、尺寸和处理结果；之后每个裁切框一行。

## 用途
几十像素宽的脸，模型在 2K 画面里画不出来。多分块、加步数、锐化引导都改变不了这一点：脸占的像素还是那么多。这个节点让每张小脸都有自己的画布。

## 原理
1. 蒙版里每一块独立的区域算一张脸。在同一镜头内按位置和大小逐帧跟随，所以路人只在前两秒出现时，后面的画面不受影响。脸被遮挡不超过一秒，会重新接上。
2. 每张脸一个裁切框，框跟随人脸移动，推镜时也跟着变大，放大到 `精修尺寸`，不带引导重画。和 Set Latent Noise Mask 一样，只重画人脸附近的区域，框里其余部分保持不变，给模型作参照。`合并尺寸` 大于 0 时，同一时间挨在一起的脸共用一个框。
3. 结果缩回原尺寸，匹配镜头颜色，羽化贴回头部。

KSamplerSelect 和 Manual Sigmas 的接法与自定义采样器相同。

## 用参考图修复主角
每个主角接一个单独的 SAM3 Track to Mask，连到主角蒙版1、2……，图片连到参考图1、2……。编号就是唯一的对应关系，不用判断谁是谁。主角跨镜头换了跟踪编号时，在 `object_indices` 里全部写上，例如 `2,7,13`。

主角不管多大都会重画，结果会向参考图靠近，而不是向视频其余部分靠近。

## 哪些脸会被重画
`蒙版` 里的都会，除了始终大于 `最大人脸` 的。不想动的脸请不要放进蒙版：没被重画的脸就不会变。

蒙版只有一层，分不清两张脸的边界。在蒙版里连在一起的脸会放在同一个框里重画，效果比单独一张脸略差。

脸是重画的，不是还原的。不同种子下长相可能不一样。
