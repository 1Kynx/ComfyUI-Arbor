# 收集

把任意数据——图片、蒙版、latent、音频、视频、文字——收集成数据：每个输入一个有名字的分支，或全部放进一个列表。

## 输入

- **输入** `inputs` · *任意 × N，连接后自动增加*  
  任意数据。每连一个就多出一个输入口。列表的所有项都放进它的分支；数据树保留自己的分支，放在 {i;…} 下。
- **模式** `mode` · *COMBO (branch per input · one list)*  
  branch per input 每个输入一个分支：第 1 个输入 → {0}，第 2 个 → {1}……（只算已连接的输入口）· one list 一个列表：全部放进 {0}，同 ComfyUI 的 Create List。
- **名字** `names` · *STRING*  
  一行一个名字，按输入顺序给分支命名。名字会成为图像网格的行标签、面板的分支名、图像滑块的页名，以及「按路径保存图像」的文件夹名。一个列表模式下，第一行给这个列表命名。
- **拆分批次** `split_batch` · *BOOLEAN*  
  把 IMAGE / MASK / LATENT 批次拆成每帧一项。

## 输出

- **数据** `data` · *任意 ×N*  
  收集到的所有项（普通数据）——普通节点逐项运行。
- **数据树** `tree` · *数据树*  
  收集到的项（数据树），每个输入一个有名字的分支。

## 对比不同流程
```
Qwen    ─► 输入0 ┐
Flux    ─► 输入1 ├─ 收集（名字：Qwen / Flux / 原图）─ 数据树 ─► 图像网格
加载图像 ─► 输入2 ┘
```
每条流程成为对比图的一行，并用名字标注。

## 按场景准备参考图
每个场景接一批参考图，打开 *拆分批次*，写上场景名：`{0} Arrival: 3 张 · {1} Village: 2 张`——可以直接接 **列表取项**、**交叉组合** 或参考生视频。

## 提示
- 手动输入文字用 **面板** 更方便；本节点用于来自其它节点的数据。
- 只算已连接的输入口，所以 `{0}`、`{1}`……不会有空缺。
