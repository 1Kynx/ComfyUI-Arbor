# 列表排序

对每个分支排序——数字在前（按数值），文本在后（按字母）——或反转顺序。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **顺序** `order` · *COMBO (ascending · descending · reverse)*  
  ascending 升序 · descending 降序 · reverse 反转（不排序，只把顺序倒过来）。

## 输出

- **数据树** `tree` · *数据树*  
  处理后的数据树。

## 示例
`3, b, 1, a` → 升序 `1, 3, a, b` · 降序 `b, a, 3, 1` · 反转 `a, 1, b, 3`
