# 分流

按模式把项分成 A（为真）和 B（为假）（对应 Grasshopper 的 Dispatch）。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **模式** `pattern` · *STRING / BOOLEAN / 数据树*  
  输入重复模式（'T F'、'true,false'、'1 0 1'、'TFT'），或接入 BOOLEAN 值 / 布尔数据树（例如表达式 'x > 2'），按分支匹配。

## 输出

- **A** · *数据树*  
  模式为真的项。
- **B** · *数据树*  
  模式为假的项。

## 示例
模式 `T F`：`a, b, c, d` → A `a, c` · B `b, d`
