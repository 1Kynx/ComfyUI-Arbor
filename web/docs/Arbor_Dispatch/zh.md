# 分流

按真 / 假模式拆分：A 是为真的项，B 是为假的项——只用 A 就是剔除（对应 Grasshopper 的 Dispatch 和 Cull Pattern）。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **模式** `pattern` · *STRING / BOOLEAN / 数据树*  
  输入重复模式（'T F'、'true,false'、'1 0 1'、'TFT'），或接入 BOOLEAN 值 / 布尔数据树（例如表达式 'x > 2'），按路径匹配——父分支上的值作用于它的所有子分支。

## 输出

- **A** · *数据树*  
  模式为真的项——剔除时保留下来的就是它。
- **B** · *数据树*  
  模式为假的项。

## 示例
| 模式 | `a, b, c, d` → A | B |
|---|---|---|
| `T F` | a, c | b, d |
| `F F T` | c | a, b, d |
| 表达式 `i % 2 == 1` | b, d | a, c |
| 原生 Boolean = False | （空） | 全部 |

要剔除列表中的项，接 A、不接 B 即可。
