# XY 组合列表

一步从参数值到批量运行：x、y（和 z）的所有组合输出为对齐的原生列表，并输出给「列表 → 数据树」用的网格形状。

## 输入

- **x** · *任意*  
  行的取值：数据树、列表或单个值（例如写着 3 / 5 / 7 的面板）。
- **y** · *任意，可选*  
  列的取值（可选）。
- **z** · *任意，可选*  
  可选的第三个参数：作为列，行变为 x × y。
- **模式** `mode` · *COMBO (cross · zip)*  
  cross 交叉：所有组合 · zip 配对：逐项对应（最长列表，不够时重复最后一项）。

## 输出

- **x** · *任意 ×N*  
  每次运行的 x——接到任意参数输入（cfg、步数、种子……），被接的节点会对每种组合各运行一次。
- **y** · *任意 ×N*  
  每次运行的 y。
- **z** · *任意 ×N*  
  每次运行的 z（未接 z 时为空值）。
- **形状** `shape` · *数据树*  
  运行结果的网格布局——接「列表 → 数据树」的形状。它的项就是列的取值，也可以直接当「数据树 → 网格」的列标签。
- **数量** `count` · *INT*  
  运行次数。

## 五个节点做 XY 对比图
```
面板(cfg) ─x─┐               ┌─ x ─► KSampler.cfg ─┐
             ├─ XY 组合列表 ──┤─ y ─► CLIP 文本 ────┴─► VAE 解码 ─► 列表 → 数据树 ─► 数据树 → 网格
面板(提示词)─y┘               └─ 形状 ─────────────────────────────┘
```
1. 在两个 **面板** 里分别输入 x 和 y 的取值，接它们的 *数据树* 输出。
2. 把 *x* / *y* 接到想要变化的参数上——普通节点会对每种组合各运行一次。
3. 用 **列表 → 数据树**（*形状* 接本节点）收集图片，再接 **数据树 → 网格**（行标签 = x 的面板，列标签 = *形状*）。

示例模板：*模板 → ComfyUI-Arbor → arbor_xy_sampler*。

## 提示
- 3 × 4 个值 = 运行 12 次；上限 1 万次。
- 任何参数都能接这些输出：把 *x* 拖到参数上，它就会变成输入口。
