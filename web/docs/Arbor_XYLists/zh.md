# XY 组合列表

从取值到批量运行：x、y（和 z）的所有组合输出为对齐的普通数据——接到普通节点上，每种组合运行一次——并输出运行结果的结构。只接 x 时，可把任意数据树展开成普通数据。

## 输入

- **x** · *任意*  
  行的取值——或任意要展开成普通数据的数据树。
- **y** · *任意，可选*  
  列的取值（可选）。
- **z** · *任意，可选*  
  可选的第三个参数：作为列，行变为 x × y。
- **模式** `mode` · *COMBO (cross · zip)*  
  cross 交叉：所有组合 · zip 配对：逐项对应（最长列表，不够时重复最后一项）；结构沿用最长那个输入的分支（依次看 x、y、z）——它是普通列表时就是单行。

## 输出

- **x** · *任意 ×N*  
  每次运行的 x——接到任意参数输入（cfg、步数、种子……），被接的节点会对每种组合各运行一次。
- **y** · *任意 ×N*  
  每次运行的 y。
- **z** · *任意 ×N*  
  每次运行的 z（未接 z 时为空值）。
- **结构** `shape` · *数据树*  
  运行结果的布局：接「图像网格」排成行 × 列，或接「构建数据树」收回成数据树。每行以 x 的取值命名，项就是列的取值，所以图像网格会自动标注行和列。只接 x 时，它就是 x 自己的数据树。
- **数量** `count` · *INT*  
  运行次数。

## 四个节点做 XY 对比图
```
面板(cfg) ─x─┐               ┌─ x ─► KSampler.cfg ─┐
             ├─ XY 组合列表 ──┤─ y ─► CLIP 文本 ────┴─► VAE 解码 ─► 图像网格
面板(提示词)─y┘               └─ 结构 ────────────────────────────────┘
```
1. 在两个 **面板** 里分别输入 x 和 y 的取值（或用 **数列**），接到 x、y 上。
2. 把 *x* / *y* 接到想要变化的参数上——普通节点会对每种组合各运行一次。
3. 解码后的图片和 *结构* 一起接 **图像网格**：自动排成行 × 列，行和列都自动标注——行以 x 命名，列是 y 的取值。

示例模板：*模板 → ComfyUI-Arbor → arbor_qwen_lora_sweep*。

## 展开任意数据树
只接 *x*：*x* 输出它的所有项（普通数据，普通节点逐项运行），*结构* 就是这棵树本身。逐项处理后，用 **构建数据树**（*结构* 接这里）把结果收回原来的分支。**数据树转数据** 用更小的节点做同样的事。

## 并排展开两棵树
两棵结构相同的数据树——例如 **交叉组合** 输出的图片和对应的编辑指令——分别接 *x* 和 *y*，用 **zip** 模式：两者都变成普通数据，第 k 项对第 k 项，*结构* 沿用最长那个输入的分支，用来把结果收回去。模板：*arbor_qwen_edit_by_scene*。

## 提示
- 3 × 4 个值 = 运行 12 次；上限 1 万次。
- 任何参数都能接这些输出：把 *x* 拖到参数上，它就会变成输入口。
