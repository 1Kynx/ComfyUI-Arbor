# 合并

合并多棵数据树——一个节点包含 Grasshopper 的 Merge 和 Entwine。

## 输入

- **数据树** `trees` · *任意 × N，连接后自动增加*  
  要合并的数据树，每连一个就多出一个输入口。
- **模式** `mode` · *COMBO (merge · entwine)*  
  merge 合并：相同路径的项按输入顺序追加 · entwine 编织：第 i 个输入放在 {i;…} 下，各输入保持分开。

## 输出

- **数据树** `tree` · *数据树*  
  处理后的数据树。

## 示例
`{0}: a` 和 `{0}: b · {1}: c`：
- merge 合并 → `{0}: a, b · {1}: c`
- entwine 编织 → `{0;0}: a · {1;0}: b · {1;1}: c`
