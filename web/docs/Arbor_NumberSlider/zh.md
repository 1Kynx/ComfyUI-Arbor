# 数值滑块

Grasshopper 风格的数值滑块：在最小值和最大值之间拖动取值。小数位 = 0 时为整数。

## 输入

- **数值** `value` · *FLOAT*  
  当前数值（由滑块设置）。
- **最小值** `min` · *FLOAT*  
  范围下限（点击左侧数字修改）。
- **最大值** `max` · *FLOAT*  
  范围上限（点击右侧数字修改）。
- **小数位** `decimals` · *INT*  
  精度：0 = 整数，2 = 步长 0.01（点击步长按钮切换）。

## 输出

- **数值** `value` · *FLOAT*  
  FLOAT 形式的数值。
- **整数** `int` · *INT*  
  四舍五入为 INT——用于步数、种子、数量。

## 用法
- **拖动**滑轨取值；按住 **Shift** 拖动可精细调节（10 倍精度）。
- 在滑轨上**滚动鼠标**或按 **← / →**（加 Shift ×10）按步长加减。
- **双击**大号数字直接输入精确值。
- 点击两端的**最小值 / 最大值**修改范围，点击**步长**按钮切换精度。

## 提示
- *数值* 可接任何 FLOAT 参数（cfg、denoise、LoRA 强度），*整数* 接 INT 参数（步数、种子）。
- 拖动时，下游的实时面板会跟着变化。
