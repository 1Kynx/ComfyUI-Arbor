# 数值滑块

Grasshopper 风格的数值滑块：在滑条上拖动，在最小值和最大值之间取值；单击可直接输入。步长为 1 时为整数。

## 输入

- **数值** `value` · *FLOAT*  
  当前数值——在滑条上设置。
- **最小值** `min` · *FLOAT*  
  范围下限（点击滑条下方左侧的数字修改）。
- **最大值** `max` · *FLOAT*  
  范围上限（点击滑条下方右侧的数字修改）。
- **步长** `step` · *FLOAT*  
  数值对齐到 最小值 + k × 步长：1 = 整数，0.05 = 以 0.05 为间隔，0 = 连续取值。同时决定显示几位小数。

## 输出

- **数值** `value` · *FLOAT / INT*  
  一个输出兼顾所有数值输入：INT（步数、种子）和 FLOAT（cfg、denoise）都能直接连接。整数以 INT 输出，其余以 FLOAT 输出。

## 用法
- 在滑条上**拖动**——数值跟随鼠标位置。拖动时按住 **Shift** 可精细调节（10 倍精度）。
- **单击**滑条（不拖动）直接输入数值；Enter 确认，Esc 取消。输入超出范围的值时，范围会自动扩展。
- 在滑条上**滚动鼠标**或按 **← / →** 按一个步长加减（按住 Shift 为 10 个步长）。
- 滑条下方：点击 **最小值**、**步长** 或 **最大值** 即可修改。

## 示例
| 最小值 · 步长 · 最大值 | 取值 |
|---|---|
| 0 · 0.05 · 1 | 0, 0.05, 0.10, … 1 |
| 1 · 1 · 50 | 整数——步数、批次大小 |
| 0 · 0 · 1 | 任意值（最多显示 4 位小数） |

## 提示
- 唯一的 *数值* 输出可接任何数值输入——FLOAT（cfg、denoise、LoRA 强度）或 INT（步数、种子、批次大小）。把它拖到参数上，参数会变成输入口。
- 接 INT 参数时请用整数滑块（步长 1）：像 7.5 这样的值会以 FLOAT 传出。
- 拖动时，下游的实时面板会跟着变化。
