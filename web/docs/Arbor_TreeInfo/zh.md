# 数据树统计

分支数、项数、深度和路径列表。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。

## 输出

- **分支数** `branches` · *INT*  
  分支的数量。
- **项数** `items` · *INT*  
  所有项的总数。
- **深度** `depth` · *INT*  
  最长路径的层数。
- **路径** `paths` · *STRING*  
  每个分支一行：路径和项数。

## 提示
- 只是想看一眼的话，**面板** 能实时显示同样的信息；需要把这些数字接到下游（例如作为等差数列的数量）时用本节点。
