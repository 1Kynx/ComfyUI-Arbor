# Sort List

Sort every branch — numbers first (by value), then text (alphabetically).

## Inputs

- **tree** · *any*  
  A data tree, or any value / list (becomes branch {0}).
- **descending** · *BOOLEAN*  
  Largest first.

## Outputs

- **tree** · *TREE*  
  The resulting tree.

## Example
`3, b, 1, a` → `1, 3, a, b`
