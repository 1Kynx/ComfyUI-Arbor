# 分组

把每个分支切成每组 size 项：{p} → {p;k}（对应 Grasshopper 的 Partition）。

## 输入

- **数据树** `tree` · *任意*  
  数据树，或任意值 / 列表（会成为分支 {0}）。
- **每组项数** `size` · *INT*  
  每组的项数；最后一组可能不足。

## 输出

- **数据树** `tree` · *数据树*  
  处理后的数据树。

## 示例
每组 2 项：`{0}: a, b, c, d, e` → `{0;0}: a, b · {0;1}: c, d · {0;2}: e`

适合把一串平铺的图片排成网格的行。
