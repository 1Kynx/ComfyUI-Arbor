# 加载文件夹

加载文件夹里的所有图片；开启子文件夹后，每个文件夹就是一个分支——目录结构直接变成数据树。

## 输入

- **文件夹** `folder` · *STRING*  
  绝对路径；output/… 表示 ComfyUI 的 output 文件夹；其它相对路径都在 input 文件夹里。
- **文件匹配** `pattern` · *STRING*  
  用空格分隔的文件名模式，例如 *.png *.jpg。
- **子文件夹** `subfolders` · *BOOLEAN*  
  开启：每个子文件夹（以及本文件夹，如果里面有图）各成一个分支。关闭：只读本文件夹。
- **排序** `sort` · *COMBO (name · modified)*  
  name = 自然排序（img2 排在 img10 前）；modified = 按修改时间从旧到新。
- **数量上限** `limit` · *INT*  
  最多加载的图片总数；0 = 全部。所有图片都会载入内存，大文件夹请设上限。

## 输出

- **图像** `images` · *数据树*  
  图像数据树，每个文件夹一个分支，并以文件夹命名——图像网格用名字标注行，面板和图像滑块也会显示。
- **文件名** `names` · *数据树*  
  不带扩展名的文件名，结构相同——可作标签或给「按路径保存图像」用。
- **文件夹** `folders` · *STRING ×N*  
  文件夹名（普通数据），每个分支一个。
- **数量** `count` · *INT*  
  图片总数。

## 示例
```
photos/            →  图像 {0}：2 张   文件夹：photos
  a.png b.png
  day/             →  图像 {1}：3 张   文件夹：day
  night/           →  图像 {2}：1 张   文件夹：night
```

## 往返
**按路径保存图像** 按有名字的分支保存的文件夹（`0 · Arrival`、`1 · The village`）读回来时会恢复名字（*Arrival*、*The village*）和顺序。模板：*arbor_folder_review*。

## 提示
- 文件有增删改时，节点会自动重新读取。
- 图片保持各自的尺寸；后续需要统一尺寸时用 **智能缩放**。
