# 加载文件夹

加载文件夹里的所有图片、视频或音频；开启子文件夹后，每个文件夹就是一个以它命名的分支——目录结构直接变成数据树。

## 输入

- **文件夹** `folder` · *STRING*  
  绝对路径；output/… 表示 ComfyUI 的 output 文件夹；arbor:… 表示 Arbor 自带的示例素材；其它相对路径都在 input 文件夹里。也可以点输入框末尾的文件夹图标，用系统的文件夹窗口选择。
- **类型** `kind` · *COMBO*  
  加载什么：images 图片（IMAGE）· videos 视频（VIDEO——按需读取，下游节点用到画面时才解码）· audio 音频（AUDIO）。每种类型有自己的文件匹配。
  - **文件匹配** `pattern` · *STRING*  
    用空格分隔的文件名模式，例如 *.png *.jpg、*.mp4 *.mov 或 *.wav *.flac。
- **子文件夹** `subfolders` · *BOOLEAN*  
  开启：每个子文件夹（以及本文件夹，如果里面有匹配的文件）各成一个分支。关闭：只读本文件夹。
- **排序** `sort` · *COMBO (name · modified)*  
  name = 自然排序（img2 排在 img10 前）；modified = 按修改时间从旧到新。
- **数量上限** `limit` · *INT*  
  最多加载的文件总数；0 = 全部。图片和音频会载入内存，大文件夹请设上限。

## 输出

- **文件** `files` · *数据树*  
  图片 / 视频 / 音频组成的数据树，每个文件夹一个分支，并以文件夹命名——图像网格用名字标注行，面板和对比查看器也会显示。
- **文件名** `names` · *数据树*  
  不带扩展名的文件名，结构相同——可作标签或给「按路径保存」用。
- **文件夹** `folders` · *STRING ×N*  
  文件夹名（普通数据），每个分支一个。
- **数量** `count` · *INT*  
  文件总数。

## 示例
```
shots/             →  文件 {0}：2 个视频   文件夹：shots
  a.mp4 b.mp4
  day/             →  文件 {1}：3 个视频   文件夹：day
  night/           →  文件 {2}：1 个视频   文件夹：night
```
视频接 **数据树转数据** → 任意有 VIDEO 输入的节点（获取视频组件、保存视频……），每段运行一次；音频同理接 AUDIO 输入。

## 选择文件夹
点文件夹输入框末尾的 **文件夹图标** 打开系统的文件夹窗口。位于 ComfyUI output 文件夹里的文件夹会写成 `output/…`。窗口在运行 ComfyUI 的电脑上打开；从其它电脑访问时请直接输入路径。

## 往返
**按路径保存** 按有名字的分支保存的文件夹（`0 · Arrival`、`1 · The village`）读回来时会恢复名字（*Arrival*、*The village*）和顺序。模板：*arbor_folder_review*。

## 提示
- 文件有增删改时，节点会自动重新读取。
- 图片保持各自的尺寸；后续需要统一尺寸时用 **智能缩放**。
